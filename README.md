**Issue: ZyntaxAI doesn't work in my application**
Solution: Some full-screen games and exclusive games block overlays. Try running the application in windowed mode. Also, ensure ZyntaxAI is running in the system tray.

**Issue: The hotkey doesn't respond**
Solution: Check if the hotkey conflicts with another application. Try changing it in Settings. Also, verify ZyntaxAI is actually running (look for its tray icon).

**Issue: Translation is slow**
Solution: Slow translation usually indicates a cloud service connection issue. Check your internet connection. For offline use, switch to Ollama with a smaller, faster model.

**Issue: Can't remember if I've set up API keys**
Solution: Go to Settings > Providers to see which services are configured. You'll see a status indicator for each.
